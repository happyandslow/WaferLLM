# Documentation Updates

> Source: [https://sdk.cerebras.net/sdk-release-notes/sdk-doc-updates](https://sdk.cerebras.net/sdk-release-notes/sdk-doc-updates)

The following are the updates to the documentation on this site.

## 26 May 2025

- Documentation for SDK 1.4.0 released, including the [Version 1.4.0](sdk-release-notes/sdk-rel-notes-cumulative.md#v1-4-0) release notes.
- Added reference documentation for the SDK appliance mode API. See
  [SDK Appliance API Reference](api-docs/appliance-api.md#sdk-appliance-api-reference).
- Added reference documentation for the new `SdkLayout` program layout specification API. See
  [SdkLayout API Reference](api-docs/sdklayout-api.md#sdklayout-api-reference).

## 18 March 2025

- Improved documentation for the `mem4d_dsd` type. See [Data Structure Descriptors](csl/language/dsds.md#language-dsds).
- Added documention on controlling appliance logging level for appliance mode support.
  See [Running SDK on a Wafer-Scale Cluster](appliance-mode.md#appliance-mode).

## 20 February 2025

- Added documentation of router simulator logs. See [Debugging Guide](debug/debugging.md#debugging-guide).
- Added documentation on installing additional Python packages into the container
  Python environment. See [Installation and Setup](installation-guide.md#install-guide).

## 13 December 2024

- Documentation for SDK 1.3.0 released, including the [Version 1.3.0](sdk-release-notes/sdk-rel-notes-cumulative.md#v1-3-0) release notes.
- Added documentation for interpreting simulator logs. See [Debugging Guide](debug/debugging.md#debugging-guide).

## 28 June 2024

- Documentation for SDK 1.2.0 released, including the [Version 1.2.0](sdk-release-notes/sdk-rel-notes-cumulative.md#v1-2-0) release notes.

## 10 April 2024

- Documentation for SDK 1.1.0 released, including the [Version 1.1.0](sdk-release-notes/sdk-rel-notes-cumulative.md#v1-1-0) release notes.

## 08 January 2024

- Updated installation documentation to include information for using Lima
  and QEMU on Apple Silicon Macs.

## 11 December 2023

- Updated appliance mode documentation to reflect changes to compile
  artifacts output in Cerebras ML Software 2.1.

## 13 November 2023

- Documentation for SDK 1.0.0 released, including the [Version 1.0.0](sdk-release-notes/sdk-rel-notes-cumulative.md#v1-0-0) release notes.

  See [Debugging Guide](debug/debugging.md#debugging-guide).

## 22 December 2022
